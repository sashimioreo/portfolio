# Kane Tan · personal site

Static site, no build step. Vercel deploys every push to `main`.

- `index.html`: landing page (hero, goals, about, what I do, how it works, FAQ, contact)
- `examples.html`: case studies, served at `/examples`
- `styles.css`, `site.js`: shared styling and small scripts (WhatsApp links, nav, sticky button)
- `assets/img/`: photos and `og.jpg` (the link preview image)
- `assets/fonts/`: Poppins, self-hosted
- `vercel.json`: clean URLs (`/examples` instead of `/examples.html`)
